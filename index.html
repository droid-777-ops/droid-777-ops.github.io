Hosting on Vercel

Directory setup for winbingo.apk

Place `winbingo.webp` and `winbingo.apk` inside the `public/` directory of your Vercel project:

my-winbingo-site/
├── public/
│   ├── winbingo.webp    <-- Logo
│   └── winbingo.apk     <-- APK File
├── index.html           <-- Landing Page
└── vercel.json          <-- Headers configuration

Include a `vercel.json` file in your root folder so browsers handle `.apk` downloads correctly:

{
  "headers": [
    {
      "source": "/winbingo.apk",
      "headers": [
        {
          "key": "Content-Type",
          "value": "application/vnd.android.package-archive"
        },
        {
          "key": "Content-Disposition",
          "value": "attachment; filename=winbingo.apk"
        }
      ]
    }
  ]
}
